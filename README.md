使い方

打ち間違えた文字は、正しく打つまで先に進みません。秒数・1分あたりの文字数・正確率・ミス数をリアルタイムで表示し、クリアするとランク（S〜C）、自己ベスト、苦手なキーが出ます。
自己ベストは問題一覧に表示され、ブラウザに保存されます。
日本語のコメントは、初期設定では打たずに済むよう外してあります（打ちたいときは「コメントも打つ」をON）。
行頭のインデントは自動で飛ばします（「インデント自動」をOFFにすると自分でスペースを打つ練習になります）。
誤答例（親に relative を付けた例、Gridで flex-direction を使った例など）は、普段は一覧から隠しています。「誤答例も表示」で出せます。
「＞」は半角の「>」で打ってもOKです。
キー操作：Esc で最初からやり直し、Ctrl+→ で次の問題へ。

問題の増やし方（2通り）

画面から追加：左下の「＋ 自分のCSSを追加」にCSSを貼り付けます。追加した問題はそのブラウザに保存され、「自分で追加」の欄に並びます。
ファイルに直接書く：HTMLの中の const LESSONS = [ ... ] に1ブロック足します。追加した問題はどのPCで開いても入っているので、配布するときはこちらが便利です。書き方はファイルの先頭のコメントに書いてあります。
